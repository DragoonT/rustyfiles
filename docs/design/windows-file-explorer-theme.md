# Windows File Explorer appearance

The optional **Windows File Explorer look** switch is in Settings > Appearance. It is
off by default, stored with the app's existing settings, and can be switched at any time.
With it off, RustyFile keeps its original icon appearance.

With the switch on, the app uses Windows Shell artwork at runtime for applicable files,
folders, drives, tabs, and Recycle Bin states. Common toolbar and context-menu actions use
system glyphs: Segoe Fluent Icons on Windows 11 and Segoe MDL2 Assets on Windows 10.
Icons without a matching system glyph keep their original meaning and appearance; context
menus also use the Explorer-style presentation. The tab strip keeps its glass plus button
and its existing slide-in animation.

The command-bar More menu uses the Explorer-style popup presentation, matching the file
right-click menu. The icons do not change when the theme is off. The theme does not replace
the original icon definitions or bundle the user's separate ICO collection; turning the
switch off restores the original icons.

Some theme artwork is adapted from Icons8. The app links to Icons8 in Settings > About.
