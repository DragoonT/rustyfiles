# Windows File Explorer appearance

The optional **Use Windows File Explorer Theme** switch is in Settings > Appearance. It is
off by default, stored with the app's existing settings, and can be switched at any time.
With it off, RustyFile keeps its original icon appearance.

With the switch on, the app uses Windows Shell artwork at runtime for applicable files,
folders, drives, tabs, and Recycle Bin states. Common toolbar and context-menu actions use
Windows 11 Segoe Fluent Icons; context menus also use the Explorer-style presentation. The
tab strip's new-tab control is a plain plus sign.

The theme is selected through the existing icon resolver. It does not replace the original
icon definitions or bundle the user's separate ICO collection; turning the switch off
restores RustyFile's original icon selection.
