## Насколько быстро

<img alt="Тест скорости, нарисованный списком rustyfiles: открытие папки из 100,000 файлов занимает 281 мс в rustyfiles и 2,318 мс в File Explorer (в 8 раз быстрее); папка из 2,000 изображений — 278 мс против 2,177 мс (в 8 раз); копирование 10,000 мелких файлов — 1.8 с против 25.6 с (в 14 раз); распаковка ZIP из 10,000 файлов — 3.6 с против 32.4 с (в 9 раз)" src="docs/readme/speed.png" width="100%">

Папка из 100,000 файлов открывается за 281 мс (File Explorer: 2.3 с). Цифры получены с помощью теста скорости,
встроенного в приложение: Параметры › Тест скорости, так что вы можете проверить их на своём ПК.

<details>
<summary><b>Все измерения и способ их проведения</b></summary>

#### Открытие папки

Время от запуска приложения до момента, когда список папки перестаёт меняться, в новом окне; папка уже в кэше файлов ОС.
Медиана трёх запусков после прогрева.

| Папка | rustyfiles | File Explorer | [Files](https://files.community) |
|---|--:|--:|--:|
| Пустая папка | 281 мс | 1,006 мс | 813 мс |
| 1,000 файлов | 284 мс | 2,214 мс | 1,893 мс |
| 10,000 файлов | 286 мс | 2,221 мс | 1,053 мс |
| 100,000 файлов | 281 мс | 2,318 мс | 4,069 мс |
| 2,000 изображений (миниатюры) | 278 мс | 2,177 мс | 1,075 мс |
| Память после вывода списка из 10,000 файлов | 39 МБ | 69 МБ | 204 МБ |

Измерено на одном компьютере (Ryzen 7 9800X3D, NVMe SSD, Windows 11) 2026-11-16 с rustyfiles 0.8.6 и Files 4.3.
rustyfiles и Explorer каждый раз запускали новый процесс. Files уже работал в фоне, поэтому его времена не соответствуют
холодному запуску; он также заполняет список поэтапно, и время считается до тех пор, пока изображение не перестанет меняться.
Память — это приватный рабочий набор, та цифра, которую показывает Диспетчер задач. При включённом режиме
«продолжать работу в фоне» новое окно rustyfiles не запускает процесс и показало список папки за 93–168 мс
(2026-11-06, более ранняя версия).

#### Папка из 100,000 файлов, которая постоянно меняется

Папка открыта, выбран один файл, затем в фоне в течение 5 секунд переименовывается около 1,000 файлов в секунду:

| | |
|---|--:|
| Запуск до готового списка папки (100,001 файл) | 315 мс |
| Список следует за изменениями | каждые ~750 мс |
| Повторное чтение папки (фоновый поток) | ~70 мс |
| Работа в потоке интерфейса на одно обновление | 7–8 мс |
| Выделение и курсор | остаются на выбранном файле |

Время кадров, пока та же папка прокручивается вниз и обратно в течение 7.7 с, выделение (а значит, и область предпросмотра)
перемещается каждые полсекунды, около 680 файлов в секунду переименовываются в фоне, на дисплее 200 Гц:

| | медиана | p95 | p99 | худшее |
|---|--:|--:|--:|--:|
| Стоимость кадра в потоке интерфейса | 2.1 мс | 4.6 мс | 7.9 мс | 16.8 мс |
| Время между кадрами | 3.3 мс | 5.3 мс | 9.9 мс | 17.3 мс |

2,182 кадра за 7.7 с; один разрыв длиннее кадра при 60 Гц. Проверьте сами с помощью `RUSTYFILES_TRACE_LIVE=1`
и `RUST_LOG=warn,rf_app=info`, а кадры записывайте через `GPUI_FRAME_LOG=frames.tsv`.

#### Новая вкладка в открытом окне

| Папка | Время до готового списка |
|---|--:|
| 1,000 файлов | ~48 мс |
| 10,000 файлов | ~46 мс |
| 100,000 файлов | ~129 мс |

Каждая дополнительная вкладка занимает около 3 МБ памяти (1 вкладка: ~32 МБ, 25 вкладок: ~103 МБ).

#### Поиск по имени файла

rustyfiles ведёт индекс имён локальных дисков и отвечает на поиск из него. Поиск по всем подпапкам пользовательской папки
с 3.6 миллиона файлов и папок по запросу «rapor», время до того, как результаты на экране перестали меняться:

| | Время |
|---|--:|
| rustyfiles 0.4 | **0.38 с** |
| File Explorer | 1.8 с (самый быстрый из 4 запусков; остальные заняли 11–32 с) |

Индекс хранит каждое различное имя один раз: диск с 4.8 миллиона записей, но 490 тысячами различных имён, занимает 61 МБ.
Наблюдатель за папками поддерживает его в актуальном состоянии, пока работает rustyfiles; между запусками журнал изменений NTFS
(читается без прав администратора) показывает, какие папки изменились, поэтому при старте заново перечисляются только они:
0.2 с для C: здесь, там, где обход занимает 30 с. Данные приложений, кэши, `node_modules` и `.git` исключаются;
поиск, начатый внутри них, обходит диск:

| `*.dll` в `C:\Windows` (342,492 элемента, 116,851 папка, кэш прогрет) | Время |
|---|--:|
| rustyfiles | **7.8 с** |
| `dir /s /b` | 53 с |
| PowerShell `Get-ChildItem -Recurse` | 105 с |

Поиск идёт в шести фоновых потоках, поэтому остальная система остаётся отзывчивой, и он не переходит по соединениям (junction),
из-за чего находит на 454 дубликата меньше.

| Файл | Содержимое готово, от нажатия клавиши |
|---|--:|
| JPEG, 3840 × 2160 | 24–86 мс |
| Исходный код с подсветкой синтаксиса | 23–44 мс |

#### Архивы

Чтение RAR с помощью [rarchive](https://github.com/gelenmedya/rarchive), нашего собственного движка, в сравнении
с официальным UnRAR (декодирование и проверка каждого CRC, архивы в кэше файлов):

| Архив | UnRAR | rarchive |
|---|--:|--:|
| 1.3 ГБ, словарь 32 МБ, 195 файлов | 2.79 с | **0.28 с** (10×) |
| 400 МБ, solid | 0.95 с | **0.21 с** (4.5×) |
| 400 МБ, 520 файлов | 1.03 с | **0.063 с** (16×) |

#### Копирование и распаковка

Наши собственные движки в сравнении со встроенными в Windows (rustyfiles 0.8.6, 2026-11-16):

| | Windows | rustyfiles |
|---|--:|--:|
| Копирование 10,000 мелких файлов в 100 папках (41 МБ) | 25.6 с | **1.8 с** (14×) |
| Копирование одного файла 1 ГБ | 0.61 с | 0.44 с |
| Распаковка ZIP из 10,000 файлов | 32.4 с | **3.6 с** (9×) |

Копирование распределяет мелкие файлы по папкам, потому что потоки, пишущие в одну папку, ждут друг друга; один большой файл
ограничен диском, а не движком. Конфликты имён он обрабатывает сам (заменить, пропустить или оставить оба), умеет приостанавливать
и возобновлять, может проверять каждую копию побайтно и ограничивать скорость. Скрипт теста копирования:
`crates/rf-win/examples/copybench.rs`.

Все цифры: один компьютер (Ryzen 7 9800X3D, NVMe SSD, Windows 11), ноябрь 2026.

## Что умеет

- **Просмотр.** Вкладки, которые можно вытащить в отдельное окно, сохранённые сеансы, двухпанельный режим, виды «Таблица», «Сетка»,
  «Список» и «Столбцы», группировка, панель предпросмотра, цветные метки, Полка, сетевые ресурсы и FTP.
- **Файлы.** Отмена и повтор, массовое переименование, размеры папок по запросу, использование диска с treemap, полное контекстное
  меню Explorer, перетаскивание с любыми другими приложениями.
- **Архивы.** ZIP, 7z, RAR, tar и ISO открываются как папки; внутри ZIP, 7z и tar можно редактировать.
- **Поиск.** Индекс имён ваших дисков и быстрый поиск (<kbd>Alt</kbd>+<kbd>Space</kbd>) приложений, файлов, закладок
  и параметров Windows.
- **Windows.** По желанию — файловый менеджер по умолчанию, включая <kbd>Win</kbd>+<kbd>E</kbd> и диалоги «Открыть» и «Сохранить»
  других приложений.
- **49 языков**, по языку системы.

<details>
<summary><b>Все возможности подробно</b></summary>

**Просмотр.** Вкладки можно перетаскивать для изменения порядка или вытаскивать в новое окно. Сохраните вкладки окна,
включая разделённые панели, как именованный сеанс и откройте его позже. Новая вкладка открывает «Главную» или папку,
в которой вы находитесь (Параметры › Общие). Двухпанельный режим. Виды «Таблица», «Сетка», «Список» и «Столбцы» (список может
заполняться по столбцам, как в Explorer), компактные элементы, как компактный вид в Explorer, группировка, панель предпросмотра,
поиск, цветные метки, Полка, библиотеки, сетевые ресурсы и FTP. Столбец состояния Git. Размеры папок по запросу: нажмите
«Вычислить размер»; они запоминаются между перезапусками и могут показывать размер на диске. «Показать использование диска»
для папки или диска выводит, что занимает место, от самого большого к меньшему, рядом с treemap, по которому можно кликать.
Виртуальные папки, такие как Libraries и Gallery, открываются в rustyfiles, а устройства, которые Windows показывает в разделе
«Этот компьютер» (телефоны по USB или через Phone Link), появляются в разделе «Устройства» на «Главной». Облачные папки,
которые знает Windows (OneDrive, Proton Drive, Dropbox, MEGA и другие), есть на боковой панели.

**Файлы.** Отмена и повтор для переименований, копирований, перемещений, удаления в Корзину и сплющивания папок.
Массовое переименование. Дублировать, копировать или переместить в другую панель, а также вставить скопированный текст
или изображение как новый файл. Полное контекстное меню Explorer с «Отправить», перетаскивание с Explorer, рабочим столом,
браузерами и Outlook, а также цели для перетаскивания на вкладках, закреплённых папках, папках и программах. Отправляйте
файлы на другие компьютеры через [Ferry](#ferry) и скачивайте через [HyperDownload](#hyperdownload).

**Архивы.** ZIP, 7z, RAR, семейство tar и ISO открываются как папки, включая ZIP, 7z и RAR с паролем. Добавление, удаление
и переименование внутри ZIP, 7z и tar. Создание ZIP, 7z и tar.zst на каждом ядре. Чтение выполняет [rarchive](https://github.com/gelenmedya/rarchive),
наш собственный движок на чистом Rust (также [на crates.io](https://crates.io/crates/rarchive)): он декодирует архив WinRAR
на 1.3 ГБ в десять раз быстрее UnRAR.

**Windows.** По желанию — файловый менеджер по умолчанию: папки, <kbd>Win</kbd>+<kbd>E</kbd>, «Этот компьютер» и Корзина
открываются в rustyfiles. По желанию диалоги «Открыть», «Сохранить» и «Выбор папки» других приложений тоже открываются
в rustyfiles (Параметры › Дополнительно), а кнопка закрепления там сохраняет стартовую папку для каждого приложения.
Изображения и видео, открытые в «Фотографиях» или другом приложении из Store, приходят со своей папкой, поэтому работают
«Назад» и «Вперёд». Пути Explorer `/select,` и `shell:` работают. Mica, тёмная тема и системный акцентный цвет.
Когда игра или рендер загружают GPU, отрисовка переходит на CPU и обратно без мерцания.

**Команды в адресной строке.** Как в Explorer: нажмите <kbd>Ctrl</kbd>+<kbd>L</kbd>, введите `cmd`, `powershell`, `wt`
или `code .` и нажмите <kbd>Enter</kbd>. Текст сначала воспринимается как место (путь, диск, `%VAR%`, `shell:`); папка или файл
с таким именем в открытой папке всегда важнее. Только если такого места нет, первое слово ищется как программа, как в окне
«Выполнить», и запускается в открытой папке. Ничего не запускается из автодополнения, и права администратора не запрашиваются.
Переключатель в Параметры › Файлы и папки › Поведение его отключает.

**Упорядочивание.** Правила для папки: условия по имени, расширению, типу, размеру и возрасту и одно действие
(переместить, переместить в папку по шаблону, переименовать или отправить в Корзину). Запуск вручную показывает каждый шаг
в предпросмотре и ничего не перемещает до «Применить», а запуск можно отменить. Ничего не удаляется окончательно
и ничего не перезаписывается. Правила, которые работают сами по себе, по умолчанию выключены.

**Поиск.** Быстрый поиск (<kbd>Alt</kbd>+<kbd>Space</kbd>) находит приложения, файлы и папки, закладки браузера
и страницы параметров Windows. Часто открываемое появляется первым, а то, что вы выбрали для тех же букв раньше, становится первой строкой.

**Языки.** Их 49, по языку отображения системы (или выберите в Параметры › Общие). Интерфейс написан на турецком
и английском; остальные языки начинались с формулировок сообщества Files и дальше машинно переведены. Имена и текст на языках
с письмом справа налево читаются справа налево (спасибо @ialhabbal); сам интерфейс пока не зеркалится. Исправления приветствуются:
каждый язык — это один JSON-файл в `crates/rf-app/locales/`.

## DirectLook

Выберите файл и нажмите <kbd>Space</kbd>: видео и аудио со своим плеером, изображения, текст и код, содержимое архивов
и карточка с подробностями для всего остального. Клавиши со стрелками перемещают по папке, пока она открыта. Это отдельная
программа, поэтому тяжёлое видео никогда не нагружает файловый менеджер, а если включить её, она работает и в Explorer,
и на рабочем столе (Параметры › DirectLook).

## Ferry

Отправляйте файлы и папки на rustyfiles на других ваших компьютерах в той же сети, как AirDrop:
щёлкните правой кнопкой › **Отправить через Ferry**. Выключено, пока вы не включите его в Параметры › Ferry.

<img alt="Параметры › Ferry с двумя устройствами поблизости: сопряжённым ПК с Windows с измеренной скоростью и MacBook с оценочной; уведомление Windows спрашивает, принимать ли файлы с MacBook, а строка состояния показывает передачу на 61 процент" src="docs/readme/ferry.png" width="100%">

<sub>Рисунок Параметры › Ferry с вымышленными устройствами, в словах и разметке самого приложения.</sub>

<details>
<summary><b>Как работает Ferry</b></summary>

- Сквозное шифрование (QUIC с TLS 1.3), напрямую от устройства к устройству: без сервера, без учётной записи,
  ничего не покидает вашу сеть.
- Сопрягайте устройства так же, как Bluetooth: оба показывают один и тот же шестизначный код. Файлы сопряжённого устройства
  могут приходить без запроса; всё остальное сначала спрашивается в уведомлении.
- Вы выбираете, кто видит ваш компьютер: никто, ваши сопряжённые устройства (по умолчанию) или все на десять минут.
  Пока открыты Параметры › Ferry, его видят все, чтобы новое устройство могло его найти.
- Прерванная передача продолжается с места остановки, и каждый файл проверяется, прежде чем получить своё имя.
  Полученные файлы помечаются как загруженные, поэтому SmartScreen спросит, прежде чем запустится программа из них.
- Каждое устройство показывает оценочную скорость, а **Тест скорости** измеряет её в обе стороны за несколько секунд.
- Приложение для macOS говорит на том же протоколе, описанном в [docs/nearby-protocol.md](docs/nearby-protocol.md).
  Брандмауэр Windows может спросить про Ferry: разрешите его для частных сетей.

</details>

## HyperDownload

Собственный менеджер загрузок rustyfiles, дополнение: Параметры › Дополнения › HyperDownload › **Установить**. Один
файл по многим соединениям одновременно, приостановка и возобновление с места остановки, торренты и magnet-ссылки,
страница «Загрузки» и видео, которые воспроизводятся в DirectLook ещё до окончания загрузки. Это отдельная программа
([исходный код](https://github.com/gelenmedya/hyperdownload), MIT), которая загружается только когда вы нажимаете
«Установить», перед этим проверяется по SHA-256 и удаляется в любой момент.

## Экспериментально на Windows: HyperGlass, Dock и рабочий стол

Выключено по умолчанию и пока на ранней стадии: собрано и испытано на одном ПК с двумя мониторами. Ожидайте шероховатостей
и, пожалуйста, сообщайте о том, что найдёте. Explorer продолжает работать в фоне; ничего из Windows не удаляется и не заменяется на диске.

<img alt="Рабочий стол с Dock rustyfiles внизу (три острова: Пуск и поиск, закреплённые и запущенные приложения, трей и часы), панель «Пуск» Dock открыта слева с закреплёнными приложениями и недавними файлами, HyperSearch посередине с приложениями, найденными по запросу adobe, и центр управления справа с Wi-Fi, Bluetooth, Ethernet, играющей песней, громкостью и яркостью" src="docs/readme/shell.png" width="100%">

<sub>«Пуск», HyperSearch и центр управления, собранные из трёх скриншотов одного рабочего стола (они не открываются все одновременно).</sub>

<details>
<summary><b>Что делает каждая часть</b></summary>

- **HyperGlass** (Параметры › Оформление) — пятый фон: фон окна — это стекло, которое преломляет и матирует то, что за ним.
- **Dock** (Параметры › Dock, один переключатель) размещает три стеклянных острова внизу каждого монитора вместо панели задач
  Windows: собственная панель «Пуск» и поиск, запущенные и закреплённые приложения с превью окон, значки трея, центр управления
  и панель уведомлений. Пока он включён, нажатие клавиши Windows открывает «Пуск» Dock, а <kbd>Alt</kbd>+<kbd>Tab</kbd>
  открывает его переключатель. Выключите Dock, и вернутся штатные элементы Windows.
- **Рабочий стол**, нарисованный rustyfiles, идёт вместе с Dock: ваши обои и значки, с возможностью скруглённых углов.
- **Яркость для каждого монитора.** Windows даёт ползунок только для встроенного экрана ноутбука; в центре управления Dock
  есть ползунок для каждого монитора. Внешние мониторы настраиваются по DDC/CI, который почти все настольные мониторы
  за последние пятнадцать лет понимают по DisplayPort, HDMI и DVI. Если у монитора нет ползунка, проверьте, что DDC/CI включён
  в его собственном меню; некоторые док-станции, KVM-переключатели и адаптеры его не пропускают.

</details>

## macOS (бета)

Тот же файловый менеджер, нарисованный нативно средствами AppKit и Liquid Glass поверх того же ядра на Rust: вкладки,
двухпанельный режим, все виды, Quick Look по <kbd>Space</kbd>, архивы как папки, массовое переименование, использование диска,
Полка, цветные метки, статус Git, Connect to Server, Ferry и те же 49 языков. Dock, рабочий стол, HyperSearch и DirectLook
пока остаются на Windows, а сборка HyperDownload для Mac выйдет в собственном релизе. Apple silicon и Intel, macOS 26 (Tahoe).
Обновляется сама, как приложение для Windows.

## Установка

**Windows.** [Скачайте rustyfiles-win-Setup.exe](https://github.com/gelenmedya/rustyfiles/releases/latest/download/rustyfiles-win-Setup.exe)
(около 50 МБ) и откройте его. Если Windows пишет «Windows защитила ваш ПК», нажмите **Подробнее**, затем
**Всё равно запустить**: установщик пока не подписан кодом, а каждый релиз проверяется в
[VirusTotal](https://www.virustotal.com) (отчёты приведены в конце заметок к релизу). rustyfiles запускается сам и есть
в меню «Пуск». Пароль администратора не нужен; обновления устанавливаются тихо, в фоне.

**macOS (бета).** [Скачайте rustyfiles-mac.dmg](https://github.com/gelenmedya/rustyfiles/releases/latest/download/rustyfiles-mac.dmg),
откройте его и перетащите rustyfiles в «Программы». Приложение подписано и нотариально заверено Apple, поэтому открывается
как любое другое приложение для Mac.

<details>
<summary><b>Scoop, портативная версия, ARM64, файловый менеджер по умолчанию, удаление</b></summary>

**Через [Scoop](https://scoop.sh):**

```powershell
scoop bucket add rustyfiles https://github.com/gelenmedya/scoop-rustyfiles
scoop install rustyfiles/rustyfiles
```

**Портативная версия или ARM64:** портативный zip и установщик ARM64 (`rustyfiles-win-arm64-Setup.exe`) есть на странице
[Releases](https://github.com/gelenmedya/rustyfiles/releases). Требуется Windows 11 (Windows 10 не проверялась).
Linux запланирован.

**Папки и <kbd>Win</kbd>+<kbd>E</kbd> в rustyfiles:** включите Параметры › Дополнительно › Сделать файловым менеджером
по умолчанию. Это можно отключить в любой момент.

**Удаление** как у любой программы: Параметры Windows › Приложения. Всё, что изменил rustyfiles, возвращается
к File Explorer.

**Диалоги «Открыть» и «Сохранить» в других приложениях не работают или падают** после того, как файлы rustyfiles были удалены
без деинсталляции (антивирус, сбой обновления)? Повторный запуск rustyfiles это исправит. Если он больше не запускается,
эта команда PowerShell вернёт каждому приложению стандартный диалог Windows:

```powershell
Remove-Item -Recurse "HKCU:\Software\Classes\CLSID\{DC1C5A9C-E88A-4dde-A5A1-60F82A20AEF7}", "HKCU:\Software\Classes\CLSID\{C0B4E2F3-BA21-4773-8DBA-335EC946EB8B}"
```

</details>

<details>
<summary><b>Сборка из исходников</b></summary>

Нужны [Rust](https://rustup.rs) версии 1.95 или новее и Visual Studio Build Tools с нагрузкой
«Desktop development with C++» (одна зависимость, zstd, компилирует код на C).

```powershell
git clone https://github.com/gelenmedya/rustyfiles
cd rustyfiles
.\scripts\install.ps1            # builds, then installs for your user
.\scripts\install.ps1 -Default   # also makes it the default file manager
.\scripts\install.ps1 -Uninstall
```

`cargo run --release -p rf-app` запускает без установки. Приложение для macOS находится в `macos/` и `crates/rf-mac`,
вне рабочей области Windows.

</details>

<details>
<summary><b>Как это сделано</b></summary>

rustyfiles написан с помощью инструментов ИИ для программирования, и это не секрет. Один разработчик решает, что будет создано
и как оно должно себя вести, проверяет каждое изменение на настоящем ПК (два монитора, повседневная работа) и отбрасывает
то, что не выдерживает проверки. ИИ пишет большую часть кода; но решает, что выходит в релиз, не он.

Что делает это честным:

- **Тесты.** Больше 4,000 автоматических тестов запускаются перед тем, как любое изменение отправляется.
- **Измерения.** Цифры скорости получены с помощью теста, встроенного в приложение (Параметры › Тест скорости),
  поэтому любой может проверить их на своём компьютере.
- **Отчёты.** Ошибки приходят от людей, которые пользуются приложением. Каждый запрос получает ответ, исправление вносится
  открыто, а тому, кто сообщил о проблеме, предлагают её проверить, прежде чем закрыть запрос.
- **Код.** Весь он здесь, под лицензией MIT, чтобы его читать и оценивать.

Почему Rust: файловый менеджер должен оставаться быстрым при 100,000 файлов в папке и никогда не терять ничьи данные.
Rust даёт скорость без сборщика мусора и отсекает целые классы сбоев до выпуска. rustyfiles — новое приложение,
написанное с нуля, а не переписанный Explorer; он работает рядом с Explorer и ничего в Windows на диске не меняет.

</details>
