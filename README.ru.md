rustyfiles — файловый менеджер для Windows, написанный с нуля на Rust. Он призван заменить
Проводник в повседневной работе: вкладки, две панели, архивы, которые открываются как папки, и
предпросмотрщик в духе Quick Look под названием DirectLook.

Окно никогда не ждёт диск. Список файлов, значки, миниатюры, контекстное меню и каждая файловая
операция выполняются вне основного потока интерфейса, поэтому медленный сетевой ресурс или папка
с 100 000 файлов не могут его заморозить.

### Открытие папки

Время от запуска приложения до момента, когда список папки перестаёт меняться, в новом окне, при том
что папка уже в кэше файловой системы ОС. Медиана трёх запусков после прогрева, измерено встроенным
в rustyfiles тестом скорости (Настройки › Тест скорости): его может запустить каждый на своём компьютере.

| Папка | rustyfiles | Проводник | [Files](https://files.community) |
|---|--:|--:|--:|
| Пустая папка | 281 мс | 1,006 мс | 813 мс |
| 1,000 файлов | 284 мс | 2,214 мс | 1,893 мс |
| 10,000 файлов | 286 мс | 2,221 мс | 1,053 мс |
| 100,000 файлов | 281 мс | 2,318 мс | 4,069 мс |
| 2,000 картинок (миниатюры) | 278 мс | 2,177 мс | 1,075 мс |
| Память после вывода списка из 10,000 файлов | 39 МБ | 69 МБ | 204 МБ |

Измерено на одной машине (Ryzen 7 9800X3D, NVMe SSD, Windows 11) 2026-11-16, версии rustyfiles 0.8.6
и Files 4.3 (0.8.5 в том же тесте заняла около 540 мс: её первая вкладка проигрывала анимацию открытия,
которой в 0.8.6 при запуске уже нет). rustyfiles и Проводник каждый запускались как новый процесс.
Files уже работал в фоне, поэтому её время — не холодный запуск; она к тому же заполняет список
порциями, и время засчитывается до того, как картинка перестаёт меняться. Память — это приватный
рабочий набор, та цифра, которую показывает Диспетчер задач; для Files — память её запущенного процесса.

Если включено «Работать в фоне», новое окно rustyfiles не запускает процесс: в более раннем замере
(2026-11-06, более ранняя версия) уже открытая папка показывалась за 93–168 мс.

### Папка из 100 000 файлов, которая постоянно меняется

Папка открыта, выбран один файл, а в фоне 5 секунд переименовывается около 1,000 файлов в секунду:

| | |
|---|--:|
| Запуск до выведенной папки (100,001 файл) | 315 мс |
| Список отслеживает изменения | каждые ~750 мс |
| Перечитывание папки (фоновый поток) | ~70 мс |
| Работа в основном потоке на каждое обновление | 7–8 мс |
| Выделение и курсор | остаются на выбранном файле |

Окно никогда не ждёт папку: перечитывание идёт вне основного потока, а само обновление занимает меньше
одного кадра при 120 Гц. Проверить можно самостоятельно: `RUSTYFILES_TRACE_LIVE=1` и `RUST_LOG=warn,rf_app=info`.

Время кадров во время этого: та же папка прокручивалась колёсиком мыши вниз и обратно 7.7 с, выделение
(а значит, и панель предпросмотра) смещалось каждые полсекунды, а в фоне переименовывалось около
680 файлов в секунду. Дисплей 200 Гц.

| | медиана | p95 | p99 | худшее |
|---|--:|--:|--:|--:|
| Стоимость кадра в основном потоке | 2.1 мс | 4.6 мс | 7.9 мс | 16.8 мс |
| Время между кадрами | 3.3 мс | 5.3 мс | 9.9 мс | 17.3 мс |

2,182 кадра за 7.7 с; один промежуток длиннее кадра при 60 Гц (16.7 мс). Свои замеры можно записать через
`GPUI_FRAME_LOG=frames.tsv` (по одной строке на кадр: его начало и его стоимость, в мс).

### Поиск по имени файла

rustyfiles хранит индекс имён локальных дисков и отвечает на поиск по нему. Поиск по всем подпапкам
пользовательской папки с 3.6 млн файлов и папок по слову «rapor», время засекалось до тех пор, пока
результаты на экране не перестанут меняться:

| | Время |
|---|--:|
| rustyfiles 0.4 | **0.38 с** |
| Проводник | 1.8 с (его лучший из 4 запусков; остальные заняли 11–32 с) |

В индексе каждое различное имя хранится один раз: диск с 4.8 млн записей, но 490 тысячами различных имён
занимает 61 МБ. Наблюдатель за папками держит его в актуальном состоянии, пока работает rustyfiles.
Между запусками журнал изменений NTFS (читается без прав администратора) сообщает, какие папки изменились,
поэтому при старте заново перечитываются только они, а не обходятся диски: здесь на C: это 0.2 с, тогда как
полный обход занимает 30 с. Данные приложений, кэши, папки `node_modules` и `.git` в индекс не попадают;
поиск, запущенный внутри такой папки, обходит диск:

`*.dll` в `C:\Windows`: 342,492 элемента в 116,851 папках, кэш файлов прогрет.

| Способ | Время |
|---|--:|
| rustyfiles | **7.8 с** |
| `dir /s /b` | 53 с |
| PowerShell `Get-ChildItem -Recurse` | 105 с |

rustyfiles ищет в шести фоновых потоках с низким приоритетом, поэтому остальная машина остаётся отзывчивой.
Он не проходит по точкам соединения (junction), из-за этого находит на 454 дубликата меньше.

### Копирование и распаковка

Тот же тест скорости, наши собственные движки против встроенных в Windows (rustyfiles 0.8.6, 2026-11-16):

| | Windows | rustyfiles |
|---|--:|--:|
| Копирование 10,000 мелких файлов в 100 папках (41 МБ) | 25.6 с | **1.8 с** (14×) |
| Копирование одного файла 1 ГБ | 0.61 с | 0.44 с |
| Распаковка ZIP из 10,000 файлов | 32.4 с | **3.6 с** (9×) |

Копирование использует собственный параллельный движок, который раскладывает мелкие файлы по разным папкам,
потому что потоки, пишущие в одну папку, ждут друг друга. Один большой файл ограничен диском, а не движком
(в более раннем замере Windows была быстрее на несколько мс). Поиск по имени в тестовых папках
(123,000 записей) занял 55 мс.

Конфликты имён оно тоже обрабатывает само (заменить, пропустить или сохранить оба, для всех или для каждого
файла), умеет приостанавливать и возобновлять работу, может проверить каждую копию побайтно и ограничить скорость.

Все числа: одна машина (Ryzen 7 9800X3D, NVMe SSD, Windows 11), ноябрь 2026. Открытие папки, копирование
и распаковка взяты из встроенного теста скорости (Настройки › Тест скорости); другие тестовые скрипты есть
в репозитории (`crates/rf-win/examples/copybench.rs` для копирования).

## Что умеет

**Просмотр.** Вкладки можно перетаскивать, чтобы менять их порядок, или вынимать в новое окно. Вкладки окна,
включая разделённые панели, можно сохранить как именованный сеанс и открыть позже; его имя стоит рядом с
вкладками. Новая вкладка открывает «Главную» или ту папку, в которой вы находитесь (Настройки › Общие).
Две панели. Виды «Подробно», «Сетка», «Список» и «Колонки» (список может заполняться по столбцам, как в
Проводнике), группировка, панель предпросмотра, поиск, цветные метки, «Полка», «Библиотеки», сетевые ресурсы
и FTP. Столбец состояния Git. Размеры папок по требованию: нажмите «Вычислить размер»; результаты помнятся
между перезапусками и могут показываться как размер на диске. «Показать использование диска» для папки или
диска выводит, что занимает место, от самого большого к меньшему, рядом с кликабельной древовидной картой
(C:\Windows, 341 тысяча записей: занято 26 МБ). Виртуальные папки, такие как «Библиотеки» и «Галерея», открываются
в rustyfiles, а устройства, которые Windows показывает в разделе «Этот компьютер» (телефоны по USB или
«Связь с телефоном»), появляются в разделе «Устройства» на «Главной»; эту часть ещё не пробовали на настоящем телефоне.

**Файлы.** Отмена и повтор для переименований, копирования, перемещений, удаления в Корзину и выравнивания папок.
Массовое переименование. Дублирование, копирование или перемещение в другую панель, вставка скопированного текста
или картинки как нового файла. Полное контекстное меню Проводника с пунктом «Отправить», перетаскивание в Проводник,
на рабочий стол, в браузеры и Outlook, а также цели для перетаскивания на вкладках, закреплённых папках, папках
и программах. Отправляйте файлы на другие свои компьютеры через [Ferry](#ferry), а скачивайте через
[HyperDownload](#hyperdownload).

**Архивы.** ZIP, 7z, RAR, семейство tar и ISO открываются как папки, включая защищённые паролем ZIP, 7z и RAR.
Добавление, удаление и переименование внутри ZIP, 7z и tar. Создание ZIP, 7z и tar.zst с использованием всех
ядер процессора. Чтение выполняет [rarchive](https://github.com/gelenmedya/rarchive), наш собственный движок
на чистом Rust (также [на crates.io](https://crates.io/crates/rarchive) для других проектов на Rust): он
распаковывает архив WinRAR на 1.3 ГБ в десять раз быстрее UnRAR.

**Windows.** По желанию — файловый менеджер по умолчанию: папки, <kbd>Win</kbd>+<kbd>E</kbd>, «Этот компьютер»
и «Корзина» открываются в rustyfiles. По желанию диалоги «Открыть», «Сохранить» и «Выбор папки» других программ
тоже открываются в rustyfiles (Настройки › Дополнительно), а кнопка-булавка в них сохраняет начальную папку для
каждого приложения. Картинки и видео, открытые в «Фотографиях» или другом приложении из Microsoft Store, приходят
вместе со своей папкой, поэтому работают «Назад» и «Вперёд». Пути Проводника `/select,` и `shell:` работают.
Mica, тёмная тема и системный акцентный цвет. Когда игра или рендер полностью загружает видеокарту, отрисовка
переходит на процессор и обратно без мерцания.

**Команды в адресной строке.** Как в Проводнике: нажмите <kbd>Ctrl</kbd>+<kbd>L</kbd>, введите `cmd`,
`powershell`, `wt` или `code .` и нажмите <kbd>Enter</kbd>. Текст сначала принимается за место (путь, диск,
`%VAR%`, `shell:`); папка или файл с таким именем в открытой папке всегда важнее. Только если такого места нет,
первое слово ищется как программа, как это делает окно «Выполнить», и запускается в открытой папке, а остальное
становится её аргументами. Ничего не запускается из автодополнения, и права администратора не запрашиваются.
Переключатель в Настройки › Файлы и папки › Поведение это отключает.

**Упорядочивание.** Правила для папки: условия по имени, расширению, типу, размеру и возрасту и одно действие
(переместить, переместить в папку, построенную по шаблону, переименовать или отправить в Корзину). Запуск вручную
показывает каждый шаг в предпросмотре и ничего не перемещает до «Применить», а запуск можно отменить. Ничто не
удаляется окончательно и ничто не перезаписывается. Правила, которые срабатывают сами, по умолчанию выключены.

**Поиск.** Быстрый поиск (<kbd>Alt</kbd>+<kbd>Space</kbd>) находит приложения, файлы и папки, закладки браузера
и страницы параметров Windows. Что вы открываете часто, идёт первым, а то, что вы выбирали раньше по тем же
первым буквам, стоит первой строкой.

**Языки.** Их 49, по языку экрана Windows (или выберите в Настройки › Общие). Интерфейс написан на турецком
и английском; остальные языки начаты с формулировок сообщества Files и дальше переведены машинным переводом.
Арабский, иврит и персидский переведены, а имена и текст справа налево читаются справа налево (спасибо @ialhabbal);
сам интерфейс пока не зеркалится. Исправления приветствуются: каждый язык — это один JSON-файл в `crates/rf-app/locales/`.

## DirectLook

Выделите файл и нажмите <kbd>Space</kbd>. DirectLook откроет окно предпросмотра: видео и аудио (со своим
проигрывателем), изображения, текст и код, содержимое архивов и карточку с подробностями для всего остального.
Клавиши со стрелками переключают файлы в папке, пока окно открыто.

Он работает как отдельная программа, `directlook.exe`, поэтому тяжёлое видео никогда не нагружает файловый
менеджер, и ни одна из программ не может уронить другую. Он работает в rustyfiles, а если его включить, то и в
Проводнике, и на рабочем столе. Настройки находятся в Настройки › DirectLook.

## Ferry

Отправляйте файлы и папки на rustyfiles на ваших других компьютерах в той же сети, как AirDrop:
щёлкните правой кнопкой › **Отправить через Ferry**.

<img alt="Настройки › Ferry: два ближайших устройства — подключённый компьютер с Windows с измеренной скоростью и MacBook с оценочной скоростью; уведомление Windows спрашивает, принимать ли файлы с MacBook, а строка состояния показывает передачу на 61 процент" src="docs/readme/ferry.png" width="100%">

<sub>Рисунок «Настройки › Ferry» с выдуманными устройствами, в тексте и оформлении самого приложения.</sub>

- Шифруется от конца до конца (QUIC с TLS 1.3), напрямую от устройства к устройству: без сервера, без учётной
  записи, ничто не покидает вашу сеть.
- Соединяйте устройства так же, как подключаете Bluetooth: на обоих показывается один и тот же шестизначный код.
  Файлы с подключённого устройства могут приходить без вопроса; все остальные сначала спрашиваются в уведомлении.
- Вы решаете, кто видит ваш компьютер: никто, ваши подключённые устройства (по умолчанию) или все — на десять минут.
  Пока открыты Настройки › Ferry, его видит каждый, чтобы новое устройство могло его найти.
- Прерванная передача продолжается с того места, где остановилась, и каждый файл проверяется до того, как получает
  своё имя. Полученные файлы помечаются как загруженные, поэтому SmartScreen спрашивает перед запуском любой
  программы из них.
- У каждого устройства показана оценочная скорость, а **Проверить скорость** измеряет её в обе стороны за несколько секунд.
- Приложение для macOS, которое скоро выйдет, говорит на том же протоколе, описанном в
  [docs/nearby-protocol.md](docs/nearby-protocol.md).

Ferry выключен, пока вы не включите его в Настройки › Ferry. Брандмауэр Windows может спросить о нём: разрешите
для частных сетей.

## Экспериментально: HyperGlass, Dock и рабочий стол

Они выключены по умолчанию и пока ранние. Их создали и опробовали на одном компьютере с двумя мониторами, а некоторые
части почти не использовались. Ждите шероховатостей и, пожалуйста, сообщайте о том, что найдёте.

<img alt="Рабочий стол с Dock rustyfiles внизу (три островка: «Пуск» и поиск, закреплённые и запущенные приложения, область уведомлений и часы); слева открыта панель «Пуск» Dock с закреплёнными приложениями и недавними файлами; в центре HyperSearch с приложениями, найденными по запросу adobe; справа центр управления с Wi-Fi, Bluetooth, Ethernet, играющей песней, громкостью и яркостью" src="docs/readme/shell.png" width="100%">

<sub>«Пуск», HyperSearch и центр управления, собраны из трёх снимков одного рабочего стола (они не открываются все сразу).</sub>

- **HyperGlass** (Настройки › Оформление) — пятый фон: фон окна — стекло, которое искажает и матирует то, что за ним.
- **Dock** (Настройки › Dock, один переключатель) ставит три стеклянных островка внизу каждого монитора вместо панели
  задач Windows: собственную панель «Пуск» и поиск, запущенные и закреплённые приложения с предпросмотром окон,
  значки области уведомлений, центр управления и панель уведомлений. Пока он включён, панель задач Windows скрыта,
  нажатие клавиши Windows открывает «Пуск» Dock, а <kbd>Alt</kbd>+<kbd>Tab</kbd> открывает его переключатель.
  Выключите Dock, и собственные элементы Windows вернутся.
- **Рабочий стол**, который рисует rustyfiles, идёт вместе с Dock: ваши обои и значки, с параметром скруглённых углов.

Проводник продолжает работать под всем этим; ничто из Windows не удаляется и не заменяется на диске.

### Яркость каждого монитора

В Windows ползунок яркости есть только у собственного экрана ноутбука. У **каждого монитора** в центре управления
Dock есть свой: включите Настройки › Dock, затем щёлкните значок сети или громкости справа на Dock. Внешние мониторы
настраиваются по **DDC/CI** — стандарту, на котором за последние пятнадцать лет говорит почти каждый настольный
монитор, через DisplayPort, HDMI и DVI. Если у монитора нет ползунка, проверьте в собственном меню монитора, включён
ли DDC/CI; некоторые док-станции, KVM-переключатели и адаптеры его не пропускают. Собственный экран ноутбука
настраивается так же, как ползунок Windows (на ноутбуке пока не проверяли).

## HyperDownload

Собственный менеджер загрузок rustyfiles, дополнение: Настройки › Дополнения › HyperDownload › **Установить**. Это
отдельная программа ([исходный код](https://github.com/gelenmedya/hyperdownload), MIT), которая скачивается только
когда вы нажмёте «Установить», и проверяется по SHA-256 перед запуском; её можно удалить в любой момент.

- **Загрузка по ссылке** из контекстного меню папки: один файл по многим соединениям сразу, приостанавливается и
  продолжается с места остановки, в том числе после перезапуска. Вставьте ссылку в папку, и rustyfiles предложит
  скачать её туда.
- **Торренты и magnet-ссылки** с окном выбора нужных файлов торрента. Файл `.torrent` скачивается из собственного меню.
- **Страница «Загрузки»** со всеми загрузками, их частями и прогрессом, а также завершёнными; прогресс показан и в
  Центре состояния.
- **Просмотр во время загрузки:** видео воспроизводится в DirectLook ещё до окончания загрузки.

## Установка

Установка занимает три щелчка и не требует технических знаний:

1. **[Скачайте rustyfiles-win-Setup.exe](https://github.com/gelenmedya/rustyfiles/releases/latest/download/rustyfiles-win-Setup.exe)** (около 50 МБ).
2. Откройте его. Если Windows покажет «Windows защитила ваш компьютер», нажмите **Подробнее**, затем
   **Выполнить в любом случае**. (Установщик пока не подписан кодом; это единственная причина предупреждения.
   Установщики каждого выпуска проверяются в [VirusTotal](https://www.virustotal.com): ссылки на отчёты находятся
   в конце заметок к выпуску.)
3. Готово. rustyfiles откроется сам и появится в меню «Пуск».

Пароль администратора не нужен, ничего настраивать не требуется. Обновления скачиваются тихо в фоне и применяются
при следующем открытии rustyfiles.

**С [Scoop](https://scoop.sh):**

```powershell
scoop bucket add rustyfiles https://github.com/gelenmedya/scoop-rustyfiles
scoop install rustyfiles/rustyfiles
```

**Хотите, чтобы папки и <kbd>Win</kbd>+<kbd>E</kbd> открывались в rustyfiles?** Включите Настройки › Дополнительно ›
Сделать файловым менеджером по умолчанию. Выключить можно в любой момент.

**Удаление** как у любой программы: Параметры Windows › Приложения. Всё, что изменил rustyfiles, возвращается к Проводнику.

**Диалоги «Открыть» и «Сохранить» в других программах не работают или падают** после того, как файлы rustyfiles
были удалены без удаления программы (антивирус, сбойное обновление)? Повторный запуск rustyfiles это исправляет.
Если rustyfiles больше не запускается, эта команда PowerShell возвращает каждой программе стандартный диалог Windows:

```powershell
Remove-Item -Recurse "HKCU:\Software\Classes\CLSID\{DC1C5A9C-E88A-4dde-A5A1-60F82A20AEF7}", "HKCU:\Software\Classes\CLSID\{C0B4E2F3-BA21-4773-8DBA-335EC946EB8B}"
```

Предпочитаете без установщика? Портативный zip есть на странице [Releases](https://github.com/gelenmedya/rustyfiles/releases),
и установщик для ARM64 (`rustyfiles-win-arm64-Setup.exe`) тоже. Нужна Windows 11 (Windows 10 не проверялась).
Версия для macOS скоро выйдет, а Linux запланирована.

**Вопросы или идеи?** Заходите поздороваться в [Discord](https://discord.gg/K2banZ36zJ) или на
[rustyfiles.com](https://rustyfiles.com).

### Сборка из исходников

Нужны [Rust](https://rustup.rs) 1.95 или новее и Visual Studio Build Tools с компонентом «Разработка классических
приложений на C++» (одна зависимость, zstd, компилирует код на C).

```powershell
git clone https://github.com/gelenmedya/rustyfiles
cd rustyfiles
.\scripts\install.ps1            # builds, then installs for your user
.\scripts\install.ps1 -Default   # also makes it the default file manager
.\scripts\install.ps1 -Uninstall
```

`cargo run --release -p rf-app` запускает программу без установки.

## Структура проекта

| Крейт | Что содержит |
|---|---|
| `crates/rf-app` | Интерфейс и две программы: `rustyfiles` и `directlook` (`src/look/`) |
| `crates/rf-win` | Интеграция с Windows и оболочкой, движок файловых операций |
| `crates/rf-core` | Модель: расположения, история, записи |
| `crates/rf-archive` | Операции с архивами: просмотр, распаковка, создание, изменение |
| `crates/rf-player` | Видео- и аудиоплеер DirectLook |
| `crates/rustdecoder` | Наш собственный видеодвижок, в работе: MP4/MOV (в том числе фрагментированные) и MKV/WebM; H.264, HEVC, VP9 и AV1 декодируются на видеокарте через D3D11 Video, побитово совпадают с ffmpeg / dav1d в его тестах; ProRes и DNxHR декодируются на процессоре; преобразование цвета, аудио (PCM, AAC, FLAC, Opus, MP3) и синхронизация A/V. Он возьмёт на себя воспроизведение видео в DirectLook ([проект](docs/design/rustdecoder.md)) |

Интерфейс построен на [GPUI](https://gpui.rs), фреймворке редактора Zed. Его слой для Windows — форк, который
добавляет переключение GPU/CPU: [gelenmedya/gpui-pre-windows](https://github.com/gelenmedya/gpui-pre-windows).

<details>
<summary>Переменные окружения</summary>

| Переменная | Действие |
|---|---|
| `RUSTYFILES_RENDERER` = `gpu`, `cpu` или `auto` | Принудительно задать, где рисуется окно |
| `RUSTYFILES_CONFIG_DIR` = папка | Хранить настройки в другой папке (переносимый режим) |

## Как это сделано

rustyfiles написан с помощью инструментов для программирования на основе ИИ, и это не секрет. Один разработчик решает,
что будет создано и как должно вести себя, проверяет каждое изменение на настоящем компьютере (два монитора,
повседневная работа) и отбрасывает то, что не выдерживает проверки. ИИ пишет большую часть кода, но решает,
что выходит в релиз, не он.

Что держит это честным:

- **Тесты.** Больше 3,000 автоматических тестов запускаются перед тем, как любое изменение отправляется.
- **Измерения.** Цифры скорости выше получены встроенным в приложение тестом (Настройки › Тест скорости), так что
  каждый может проверить их на своём компьютере.
- **Отчёты.** Ошибки приходят от людей, которые пользуются программой. Каждый запрос получает ответ, исправление
  делается открыто, а тому, кто сообщил, предлагают его проверить, прежде чем закрыть.
- **Код.** Весь он здесь, под лицензией MIT, чтобы читать и судить.

Почему Rust: файловый менеджер должен оставаться быстрым при 100,000 файлов в папке и никогда не терять чьи-либо
данные. Rust даёт скорость без сборщика мусора и исключает целые классы падений до выхода. И rustyfiles — новое
приложение, написанное с нуля, а не переписанный Проводник: оно работает рядом с Проводником и ничего не меняет
в Windows на диске.

## Статус

rustyfiles молод, а его автор пользуется им каждый день вместо Проводника. Дорожная карта и отчёты тестирования
появятся в `docs/`. Версия для macOS уже в пути, построена на том же ядре, а Linux идёт следом.

Отчёты об ошибках и pull request приветствуются.
